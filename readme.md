# 📊 Personal Finance Dashboard - Scotiabank

This is a personal project for analyzing and visualizing personal finances using transaction data exported from **Scotiabank**.

The goal is to create an **interactive dashboard** to track income, expenses, spending categories, and balance evolution over time.

## 🚀 Tech Stack
- [Python 3.10+](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- [Plotly](https://plotly.com/python/)
- [Pandas](https://pandas.pydata.org/)
